## 🚀 How to Run Anytime (After PC Restart / Shutdown)

### Option 1: 1-Click Double Click (Easiest)
1. Open File Explorer and go to:
   `C:\Users\vicky\.gemini\antigravity-ide\scratch\tribalone`
2. **Double-click** on:
   👉 **`start_tribalone.bat`**
3. It will automatically start the server and open **`http://localhost:3000`** in your default web browser!

---

### Option 2: Using Terminal / PowerShell
1. Open **PowerShell** or **Command Prompt**.
2. Run this command to navigate to the project:
   ```powershell
   cd C:\Users\vicky\.gemini\antigravity-ide\scratch\tribalone
   ```
3. Run either command:
   ```powershell
   npm start
   ```
   *or*
   ```powershell
   node server.js
   ```
4. Open your browser and go to:
   **`http://localhost:3000`**

---

## 📁 Copying to Another Folder / Desktop
You can copy the entire `tribalone` folder to anywhere on your computer (e.g., your Desktop or `D:\projects\tribalone`).  
The project has **zero external dependencies** — double-clicking `start_tribalone.bat` will work from any folder as long as Node.js is installed on your computer.
